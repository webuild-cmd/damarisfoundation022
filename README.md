# Damaris Foundation for Premature Infants — Revised V3

## GitHub Pages upload
Upload these items directly into the repository root:
- `index.html`
- `style.css`
- `script.js`
- `assets/` (including the supplied team photographs and `damaris-logo-mark.webp`)

The full letterhead image is **not required** by the website and is not included in the assets. The site uses the prepared Damaris logo-mark asset instead.

## Important
Keep the `assets` folder in the same repository level as `index.html` so the image paths work correctly.
